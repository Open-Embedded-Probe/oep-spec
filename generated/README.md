# Registry outputs

[日本語](README.ja.md) - until OEP v1.0.0 the Japanese text is authoritative.

This directory holds the constants generated from [registry/](../registry/README.md) for implementations to take in.

The current output is [oep-v1/](oep-v1/README.md). Its README says what each language's file is for and how it is updated. The generated code is not edited by hand: change the registry and the [generator](../tools/README.md), and generate again. The READMEs are guides kept by hand.

# Open Embedded Probe Specification

Open Embedded Probe (OEP) is a protocol for interoperable embedded-development probes and hosts.

OEP v1 is not frozen yet. Until the freeze, the maintained and authoritative text is Japanese. Start with [README.ja.md](README.ja.md). English normative documents will be produced at the freeze. Every Japanese document already has its English URL (the same name without `.ja`), a placeholder that links to the Japanese text until then, so links can point at the English pages now; stale translations are not kept.
